Build that pin in those colors: background = bg, main text = ink, numbers/kicker/CTA button = acc, list box = card (no border needed on dark palettes), CTA button text = bg. Keep fonts, layout styles and the CLICK RULES the same. Log every pin with "palette": "<exact palette name>" in pin_log.json so the bot can learn which colors earn clicks. Pins without a palette field count as "cream classic". Judge at the 2026-11-29 review (too early on 2026-11-22).
- CLICK RULES (Micah approved 2026-11-19; apply to EVERY new pin, every style, from 2026-11-20 on). Why: 749 lifetime impressions and 30 saves but only 1 outbound click; list pins showed 8 of 12 items so people could read and save without visiting.
  1. HOLD BACK THE LIST: a pin may show at most 4 items of a guide (fewer is fine), then a line like "+ 10 more picks on the list" (use the guide's real remaining count). Never show more than 4 items on one image.
  2. CALL TO ACTION ON THE IMAGE: every pin has a clear tap prompt near the bottom, above the site URL, e.g. a pill/button reading "Tap for the full list + links", "See all 14 picks", or "Full list + Amazon links". Vary the wording; keep it large and readable at phone size (>= 38px). The site URL footer stays.
  3. CALL TO ACTION IN TEXT: the pin title stays keyword-first; the description keeps the search phrase first, then ends with a short prompt like "Tap to see the full list with links." before "Affiliate links." and the hashtags.
  4. NUMBER IN THE HEADLINE (2026-11-20, from the InsightPins pin review): list/headline/teaser pins put the guide's real item count in the headline, e.g. "13 Stocking Stuffers Under $15 (That Won't End Up in a Drawer)".
  5. NO FADED SMALL TEXT: subtitles, "+N more" lines and the site URL must stay readable at thumbnail size: >= 40px for subtitles/"+N more" at full opacity in ink or acc color (no light gray), site URL >= 30px.
  These rules do not change style names or the teaser test: log styles exactly as before so the bot keeps learning. Note "click rules" in the Decisions log on the first run that uses them.
